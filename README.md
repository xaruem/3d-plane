# SkyBook 3D (Boeing 737)
Локально:  pip install -r requirements.txt && python server.py → http://localhost:8000  (двойным кликом по index.html открывать НЕЛЬЗЯ: через file:// браузер блокирует модель и показывает «Не удалось загрузить модель»)
Railway:   залить папку в репозиторий — Procfile и requirements.txt уже есть.
Настройки: в index.html объект CFG (маршрут, цены, багаж, onBook — свой хук после покупки).
Покупки:   пишутся в bookings.jsonl (на Railway подключите Volume и задайте DATA_DIR=/data, иначе файл стирается при деплое).
Telegram:  переменные TG_TOKEN и TG_CHAT — бот пришлёт сообщение о каждой покупке.
Ссылка на место: https://сайт/#12A
Модели:    models/737.glb, models/sky.jpg — заменяются файлами с теми же именами.
Ночное небо: шейдерный купол (Млечный Путь, луна с фазой и ореолом, метеоры), ~14 000 мерцающих звёзд, огни городов под облаками.
Самолёт:     навигационные огни (красный/зелёный/белый), двойные стробы, красные маяки, подсветка крыла, иллюминаторы (днём тёмные, ночью тёплые; окно выбранного места ярче).
Эти эффекты привязаны к ползунку времени суток; ✨ «Лёгкое» отключает огни городов и снижает нагрузку.
